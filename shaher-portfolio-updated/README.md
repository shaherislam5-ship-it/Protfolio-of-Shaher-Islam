# Shaher — Social Media Marketing Portfolio

Static portfolio website for Shaher's freelance digital marketing services.

## Structure
- `index.html` — original Landing Page 1, preserved as the main portfolio page.
- `services/` — six dedicated service detail pages.
- `landing-pages/landing-2/`, `landing-3/`, `landing-4/` — lightweight future landing-page routes.
- `assets/` — existing supplied media plus shared detail-page styles.

## Existing functionality preserved
- Responsive navigation and layout
- Portfolio image modal
- Case-study snapshot modal
- Scroll-reveal effects
- Desktop portrait tilt
- Email-based contact form
- Existing email and WhatsApp links
