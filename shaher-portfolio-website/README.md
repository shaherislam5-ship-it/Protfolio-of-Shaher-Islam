# Shaher — Social Media Marketing Portfolio

A responsive, single-page portfolio website for Shaher's freelance digital marketing services.

## Included
- Premium dark / neon-blue 3D-inspired UI
- Responsive mobile navigation
- Hero, Services, Portfolio, Case Study, About, Process and Contact sections
- Supplied images integrated as portfolio assets
- Case-study image modal
- Scroll-reveal animations
- Desktop pointer-based 3D tilt on the hero portrait
- Mailto contact form
- Basic SEO + social share metadata

## Publish
The site is static and needs no build step.

Upload the whole folder to any static host, or upload `index.html` and the `assets/` folder together.

For GitHub Pages: push the folder to a repository and enable Pages from the repository settings.
